📚 Q-SCI Analysis History & Offline Chat Feature

Overview

This feature enhancement allows users to revisit past analyses and use the "ask the publication" feature even when not on the publication website.

Key Features Implemented

  • Analysis History Storage: Stores up to 50 past analyses with full metadata
  • Offline Chat Support: Paper context is saved with each analysis for chat functionality
  • History Browser: Browse, view, and delete past analyses
  • Historical Analysis Loading: Load any past analysis and use all features
  • Smart Context Preservation: Full paper text, title, and URL saved for offline use
  • Bilingual Support: German and English translations for all new UI elements

User Benefits

📖 Revisit Past Research: Users can now revisit any paper they've previously analyzed without having to analyze it again, saving API usage and time.
💬 Ask Questions Anytime: The chat feature works even when not on the original publication page, enabling users to ask questions about papers they analyzed days or weeks ago.
🔍 Historical Comparison: Easily compare multiple papers by loading different analyses from history.
📊 Research Organization: Keep track of all analyzed papers in one place with timestamps and quality scores.
